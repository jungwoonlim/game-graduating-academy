# 1. 정밀 단계 — 상태 수를 전부 센다

`canon/04-sinners.md#사건별-상태-변수` 표의 각 행을 **독립 이진 변수**로 전개한다. 라스푸틴만 예외다 — 정본이 변수를 *"축 B 잔존 인원 3단"* 으로 이미 정의했으므로 그 3을 그대로 쓴다.

## 1-1. 사건별 전개

| 사건 | 선행 변수 (정본 표 그대로) | 변형 종류 | **완전 조합** | **〔경계〕 뭉침** |
|---|---|---|:---:|:---:|
| **`V-01` 아르토리우스** | `V-07` / `V-04`〔증거〕 / `V-03`〔경계〕 | 세력1·증거1·경계1 | 2×2×2 = **8** | **4** |
| **`V-02` 글러트니** | `V-06` / `V-04` / `V-05`〔증거〕 | 세력2·증거1 | 2×2×2 = **8** | **8** |
| **`V-03` 라스푸틴** | 축 B 잔존 인원 (`V-01`·`V-05`·`V-07`) | 정본 고정 3단 | **3** | **3** |
| **`V-04` 골드웜** | `V-06` / `V-02` / `V-01`〔증거〕 | 세력2·증거1 | 2×2×2 = **8** | **8** |
| **`V-05` 엔비** | `V-07` / `V-01` / `V-03`〔경계〕 | 세력2·경계1 | 2×2×2 = **8** | **4** |
| **`V-06` 슬로스** | `V-04`·`V-02` / `V-07` | 세력3 | 2×2×2 = **8** | **8** |
| **`V-07` 바실리스크** | `V-01` / `V-05` / `V-06`〔협정〕 / `V-03`〔경계〕 | 세력2·협정1·경계1 | 2×2×2×2 = **16** | **8** |
| | | | **59** | **43** |

**라스푸틴 3단의 하부 구조**: 원 조합은 `V-01`·`V-05`·`V-07`의 2³ = 8이고, 그것이 잔존 인원 4값(3·2·1·0)을 거쳐 정본 3단으로 접힌다. **정본이 접은 것이므로 정밀 단계에서도 펴지 않는다.**

**`V-06`의 상납자 행**: 정본은 `V-04`·`V-02`를 한 행에 묶었으나 문면이 *"상납자가 남아 있어야 … 둘 다 무너진 뒤면"* 이므로 **정밀에서는 독립 2변수(4조합), 실용에서는 이진 1변수(2조합)** 로 읽는다. 이것이 정밀과 실용의 유일한 상태 손실원이다(§2-3).

## 1-2. 도달 가능성

**59 전부 도달 가능하다.** 각 사건의 선행 변수는 *그 사건보다 먼저 결착되었는가*뿐이고, 7건은 어떤 순열로도 배치할 수 있으므로 각 변수의 온/오프가 독립적으로 실현된다.

**단 하나의 예외가 진엔딩 경로에 있다** → §3-2(라스푸틴 자폭).

# 2. 실용 단계 — 뭉치고 층을 나눈다

## 2-1. 축약 규칙 3 **[신]**

정본이 허용한 「축 온전 / 일부 붕괴 / 뿌리·정점 붕괴」 3단 축약을 아래 규칙으로 집행한다.

| # | 규칙 | 근거 |
|:---:|---|---|
| **1** | **층이 다르면 곱하지 않고 더한다.** 〔증거〕는 삽입 문단, 〔경계〕는 어휘 치환. 본편 블록을 복제하지 않는다 | 정본 「세 종류의 변형」 표 — *"세력 파급과는 다른 층위"* |
| **2** | **뭉쳐서 등장 인물·사건 요소가 사라지면 뭉치지 않는다.** 온도·상태만 합쳐지는 경우에만 뭉친다 | 축약 허용의 취지(제작 분량)와 *"없는 것을 만들지 않는다"* 의 역방향 |
| **3** | **정본이 못박은 둘은 본편 축으로 유지한다** — 라스푸틴 3단, 슬로스 뿌리 여부(`V-06`) | 정본 「뭉치지 않는 것이 둘 있다」 |

> **규칙 2가 `V-06`과 `V-07`의 비대칭을 만든다.** `V-07`의 *"하나를 잃은 판"* 은 서술 가능하나, `V-06`의 *"하나만 남은 상태"* 는 **후임 행정처장 매수**(상납자 잔존)와 **바실리스크가 자기 사람을 밀어넣음**(협정 상대 잔존)이 서로 다른 인물의 등장이라 뭉치면 텍스트가 성립하지 않는다.

## 2-4. 장면 단위 총량

**사전/사후는 톤만 바꾼다**(정본). 따라서 본편을 복제하지 않고 **프레임 문단 2종**(사건 규모 / 수습·뒷정리 규모 + 의심도 서술)으로 처리한다. **축소 장면**은 사전 결착 회차에서 발생 주차에 남는 장면이며(`canon/06` §5-2, `calendar.md` §2-1), 같은 상태 변수를 읽되 **규모가 작으므로 어휘 치환 수준을 넘지 않는다** **[신]**.

| 층 | **정밀** | **실용** |
|---|:---:|:---:|
| 결착 장면 상태 | 59 (〔경계〕 뭉침 43) | 본편 23 + 삽입 5 + 어휘 3 = **31** |
| × 사전/사후 톤 | ×2 → **118** (86) | 프레임 문단 7 × 2 = **14** |
| + 축소 장면 (발생 주차) | +7 | 본편 7 + 상태 어휘 7 = **14** |
| **총량** | **125** (93) | **59** |

> **사용자 사전 추정 86 = 43 × 2**는 〔경계〕를 뭉친 정밀 기준과 정확히 일치했다. 〔협정〕이 추가되어 **완전 조합은 59 × 2 = 118**이 된다. 축소 장면 7을 더한 93/125가 정밀 기준 장면 수다.

# 3. 라스푸틴 — 자폭 판정선 **[신]**

## 3-1. 판정선 확정

| 항목 | 확정 |
|---|---|
| **판정 변수** | **축 B 잔존 인원** = `V-01`·`V-05`·`V-07` 중 **미결착**인 것의 수 |
| **자폭 판정선** | **잔존 0** — 셋 전부 결착된 상태에서 `V-03` 결착을 시도할 때 |
| 3단 매핑 | 잔존 **3** = 파급 없음 / 잔존 **2·1** = 저항하나 감당 가능 / 잔존 **0** = **자폭** |
| 축 A의 영향 | **없다.** 정본 *"축 A는 무반응"* |
| 사전/사후 | **동일하게 판정한다.** 산출물 동일 규정(`canon/06` §5-2). 판정 시점은 **결착 시점의 `V` 상태** |
| 결과 | **회차 종료 분기.** `K-056` 획득, `V-03` 미결착 → 7/7 불성립 → **진엔딩 불가** |

**정본 문면과 일치하는가 — 일치한다.** 정본은 *"모든 후원자를 잃고 자신만 남았음을 안다"* 로 쓰며, 그것이 잔존 0의 직역이다. *"마지막에 처리"* 라는 표현은 순번의 서술이나, **Q-48이 「순열이 아니라 상태」로 일반화했으므로 순번이 아니라 상태를 읽는다.**

> **순번 ≠ 상태.** 축 B 셋을 먼저 정리한 플레이어는 **라스푸틴이 4번째여도 자폭을 맞는다.** 이것이 순서 자유도가 새로 만드는 함정이며, 정본의 *"경고 없이 발동한다 · 남은 후원자 수를 UI에 표시하지 않는다"* 와 정합한다.

## 3-2. P-04·순열에 대한 영향

진엔딩은 7/7을 요구하므로(`balance.md` §5-5 축 2), **`V-03`이 `V-01`·`V-05`·`V-07` 셋 모두보다 뒤에 오는 순열은 진엔딩 경로가 아니다.**

| | 값 |
|---|:---:|
| 전체 순열 | 5040 |
| `V-03`이 축 B 넷 중 마지막일 확률 | 1/4 |

# 4. 회차 아키타입 — 「3 아키타입」 가설 검증

## 4-1. 판정 — **성립하지 않는다. 최소 4다**

한 회차는 7개 사건에서 **본편 블록을 하나씩** 집는다. 따라서 **어떤 사건의 본편 블록 수보다 아키타입 수가 적을 수 없다.**

| 사건 | 본편 블록 |
|---|:---:|

| **교만 + 분노** (심판하는 사람) | 아르토리우스 · 라스푸틴 | 인사 장면에서 **말수가 가장 적다.** 대화 선택지가 가장 빨리 소멸했던 회차의 자국 |
| **시기 + 색욕** (값을 매기는 사람) | 엔비 · 바실리스크 = 축 B | 인사 명단이 같아도 **그 명단을 세는 방식**이 다르다. 사람을 자산으로 세던 습관이 마지막 장면에 남는다 |
| **식탐 + 나태** (받는 사람) | 글러트니 · 슬로스 | 안티테제들과의 **거리가 가장 가깝다.** `K-019` 시점의 타격이 최대였던 회차이므로 |

> **곱하지 않는다.** 죄 2 경로는 두 죄의 개별 향미 2개가 각각 다른 모듈(안티테제 2인)에 붙고, 조합 인격 향미 1개가 정문 프레임에 붙는다. **추가 제작 단위는 0이다.**

## 6-4. 조합 인격의 발현 임계 — 2단 제안 **[신] [판]**

**현행 정의로는 조합 인격 향미 4종이 전부 사문이거나, 시기+색욕 진엔딩이 도달 불가다.**

| 읽기 | 귀결 |
|---|---|
| 조합 인격 = **높음(50~74) 2개** | 진엔딩은 죄 1~2를 **중간(25~49)** 에서 감당하는 경로다(`sin-stacks` §3-1 — *중간이 스위트스팟*). 조합 인격이 발현하지 않으므로 **Q-50이 지정한 향미 재료 4종이 전부 쓰이지 않는다** |
| 조합 인격 = **중간(25~49) 2개** | **시기+색욕**은 *"심층 호감도 경로가 통째로 막힌다"*(`06` §2-2-4). 증인 6인 **신뢰** 확보가 진엔딩 조건이므로 **`sin-stacks` §4-2의 「시기+색욕 213」 행이 도달 불가가 된다** |

**제안 — 2단으로 나눈다** **[신]**

| 단계 | 조건 | 발현 | 향미 |
|---|---|---|:---:|
| **기미** | 두 죄가 **중간(25~49)** 에 동시 도달 | 어조·NPC 반응. **선택지는 소멸하지 않는다** | **○** |
| **발현** | 두 죄가 **높음(50~74)** 에 동시 도달 | 정본 §2-2-4의 선택지 소멸 전부 | ○ |

**이 한 규칙이 두 구멍을 동시에 닫는다** — 향미 4종이 죄 2 진엔딩 경로에서 살아나고, 시기+색욕의 심층 봉쇄는 진엔딩 구간 밖(높음)에만 걸린다.

> **구간 경계 수치는 `design/sin-stacks.md` §3-1이 이미 갖고 있다. 새로 만드는 것은 「2단」이라는 규칙이다.** 규칙은 정본 소관이므로 판정하지 않고 §7-5에 올린다.

# 8. 이벤트 포맷 — `V` 상태 스키마 확정 **[신]**

`design/sin-stacks.md` §5의 `V` 키를 확장한다. **`requires.V`(진입 조건)와 `variants`(상태 선택)는 완전히 다른 층이다.**

## 8-1. 층 구조

| 필드 | 개수 | 의미 | 검수가 검사하는 것 |
|---|:---:|---|---|
| `requires` | 1 | **이벤트에 들어갈 수 있는가** | 선행 도달 가능성 |
| `frame` | **정확히 1** | 사전/사후 톤 | `timing` 두 값이 모두 정의되었는가 |
| `body` | **정확히 1** | **본편 블록 선택** | **망라성 + 배타성** |
| `insert` | **0개 이상** | 〔증거〕·〔협정〕 삽입 문단 | 앵커가 존재하는가 |
| `lexical` | **0개 이상** | 〔경계〕 어휘 치환 | 치환 키가 `text`에 있는가 |

## 8-2. 스키마

```json
{
  "id": "EV-0304",
  "kind": "villain_resolve",
  "target_V": "V-04",
  "window": { "pre": [1, 52], "post": [53, 64] },
  "slot": { "pre": 3, "post": 5 },

  "requires": {
    "K": ["K-053"],
    "V": { "set": [], "unset": [] },

  "sets": { "V": ["V-04"] },

  "state_eval": "on_resolve",

  "frame": [
    { "id": "FR-pre",  "when": { "timing": "pre"  }, "text": "..." },
    { "id": "FR-post", "when": { "timing": "post" }, "text": "..." }

      { "id": "BD-2", "when": { "V": { "unset": ["V-06"], "set": ["V-02"] } }, "text": "..." },
```

## 8-3. `when.V` 술어 문법 **[신]**

| 술어 | 의미 | 쓰이는 곳 |
|---|---|---|
| `"set": [...]` | 나열된 `V`가 **전부 결착** | 대부분 |
| `"unset": [...]` | 나열된 `V`가 **전부 미결착** | 대부분 |
| `"any_set": [...]` | 하나라도 결착 | `V-06`의 상납자 잔존 |
| `"any_unset": [...]` | 하나라도 미결착 | 〃 |
| `"count": { "of": [...], "unset_eq": n }` | **미결착 개수 = n** | **라스푸틴 잔존 인원** |
| `"count": { "of": [...], "unset_gte": n }` / `"unset_lte": n` | 이상 / 이하 | 〃 3단 |
| `"or": [ {...}, {...} ]` | 선언 | 뭉친 블록 (`V-05` 정점 흡수 등) |

같은 객체 안의 술어는 **AND**다.

**라스푸틴 3단의 표기**

```json
"body": {
  "exhaustive": true, "disjoint": true,
  "cases": [
    { "id": "BD-intact",   "when": { "V": { "count": { "of": ["V-01","V-05","V-07"], "unset_eq": 3 } } } },
    { "id": "BD-weakened", "when": { "V": { "count": { "of": ["V-01","V-05","V-07"], "unset_gte": 1, "unset_lte": 2 } } } },
    { "id": "BD-selfdestruct",
      "when": { "V": { "count": { "of": ["V-01","V-05","V-07"], "unset_eq": 0 } } },
      "terminal": "RUN_END", "sets": { "K": ["K-056"] }, "suppress_sets_V": true }
  ]
}
```

| # | 규칙 | 왜 |
